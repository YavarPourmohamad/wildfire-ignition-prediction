# wildfire-ignition-prediction
Machine learning models to predict daily ignition probability with various grid sizes (+30m) across the Western US (2000–2020). This research introduces novel spatio-temporal stratified sampling techniques to better represent ignition absence and improve predictive performance.

# Predictive Understanding of Wildfire Ignitions across the Western United States

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15644605.svg)](https://doi.org/10.5281/zenodo.15644605)

## Overview
This repository contains the data and code for modeling wildfire ignitions in the Western US. By utilizing over 500,000 records and 267 physical, biological, and social attributes, this project addresses the overestimation of fire risk through advanced machine learning and stratified sampling.

## Key Features
* **Machine Learning:** Predictive modeling of daily fire occurrence.
* **Stratified Sampling:** Novel approach to capture the complex environmental and anthropogenic conditions of "absence" locations.
* **Large-scale Data:** Integration of FPA FOD data with 20+ years of climate and social variables.
